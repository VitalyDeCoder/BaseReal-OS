1. Planet Creation Procedure

Step-by-step planet creation instructions:

  1. Approach the star close enough so that the year is not too long
  2. Set the power of the gravitational field
  3. Set the height of the synchronous orbit so that the year has an acceptable number of days
  4. Set the axial tilt to get the winter/summer effect
  5. Press the "Create Planet" button
